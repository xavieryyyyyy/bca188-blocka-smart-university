# SENTRA dashboard

Yestin Paraguya, the project lead, builds the React and TypeScript dashboard for HAYAG readings, ANDAM tickets, and the two KAHIMTANG bays. The subsystem teams build and test their own stations, then share verified messages and results for integration. Use the black-and-white SENTRA design and show when data was last received.

Start by agreeing on the response shape with the [backend team](../backend/). Make parking visible only to authorized users and show **Unknown** when a bay’s reading is missing or stale. See the [handoff requirements](../AGENTS.md#ownership-and-handoff).
