# SENTRA dashboard

The dashboard team builds the React and TypeScript interface for HAYAG readings, ANDAM tickets, and the two KAHIMTANG bays. Use the black-and-white SENTRA design and show when data was last received.

Start by agreeing on the response shape with the [backend team](../backend/). Make parking visible only to authorized users and show **Unknown** when a bay’s reading is missing or stale.
